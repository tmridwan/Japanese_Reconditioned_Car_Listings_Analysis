# Japanese-Reconditioned-Car-Listings-Analysis-
This repo analyzes Japanese reconditioned car data (japanese_reconditioned_cars_with_age.csv) with three Tableau dashboards: Market Snapshot (brand/model trends), Price and Value Trends, and Advanced Analysis. Features interactive filters (Year, Mileage, Age, Auction_Grade) and handles grades ("R", 3–5, "S").Built with Tableau and Python.
